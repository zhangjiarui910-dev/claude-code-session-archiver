# Claude Code Session Archiver · 云端会话本地备份

> 把能在浏览器里看到的 Claude Code 云端会话，保存到自己的电脑里。**非官方工具**，不是账号数据导出，也不能恢复原来的 Session 运行状态。

一个直接在浏览器控制台运行的 JavaScript 脚本。**无需安装扩展、Node.js 或配置 API**。

**当前版本：v1.2｜适配对象：Claude Code 网页版会话（Web Session）**。普通 Claude Chat 的页面结构可能不同，**目前不保证适用**。

## 它能做什么？

- **完整备份**：自动从最新消息向上滚动，逐步读取当前网页能加载出的历史会话。
- **增量备份**：选择最近一次备份的 JSON，利用消息编号确定分界，尽可能只保存新消息和已更新的内容。
- **两种文件**：导出 `.json` 供后续增量备份使用，以及可离线阅读的 `.html`。
- **本地处理**：脚本本身不主动发起网络请求，不读取 Cookie、Token 或 localStorage，不调用 Claude 内部接口。
- **异常提醒**：识别不到分界、扫描中断、前后接不上、无法确认开头等情况，会给出警告，而不是当作可靠的完整备份。

## 三分钟学会使用

**先备份一次最重要的会话做测试，检查结果是否正常。**

1. 在**电脑浏览器**里登录 Claude Code 网页版，打开要保存的具体会话。
2. 建议先**手动向上滚到最早一条消息**，确认早期内容能正常显示，再滚回聊天最底部。对于超长会话，这可能有助于提前加载内容，但**不能保证没有遗漏**。
3. 等 Claude 停止生成回复。
4. 打开本仓库的 [`cc-session-backup.js`](./cc-session-backup.js)，复制文件中的**全部代码**。也可以先下载到电脑，用记事本打开后全选复制。
5. 回到会话网页，按 `F12`（Mac 常见快捷键为 `⌘ Command + ⌥ Option + J`），找到 **Console / 控制台**，粘贴代码并按回车。**执行前请先审查代码；不要轻信来历不明的控制台脚本。**
6. 出现“选择文件”窗口时：
   - **第一次备份**：点击 **取消** → 扫描当前会话，尽可能从最新保存到最早。
   - **以后增量备份**：选择**上次生成的 JSON** → 以它作为新旧消息的对照。
7. 运行期间保持**这个会话标签页在前台**，不要在当前会话里发送消息，不要滚动或操作聊天区域。完成后浏览器会下载 **JSON + HTML** 两个文件。
8. 用浏览器打开 HTML 阅读内容，并查看顶部有没有**不完整、可能遗漏**等警告。JSON 请妥善保存，**后续备份还要用**。

> 如果文件选择窗口没有弹出，可以在**聊天内容的空白处点一下**；脚本会尝试重新打开文件选择框。浏览器若拦截下载，可在检查完浏览器权限后重试。

### 第二次备份怎么做？

重复上面的步骤，但这次选择**最近一次保存的 JSON**。脚本找到先前备份的消息编号时，会只保存后面的新增内容；如果没找到可靠的分界，可能改为完整重扫，或者标注为不完整，**不会默默把旧内容伪装成新增**。

**注意：增量文件不是“历史记录全集”。** 每次导出的 JSON 和 HTML 都要保留；不要只留最后一份。你可以为每个会话单独建立文件夹存放。

## 看懂导出结果

| 文件 | 用途 |
| --- | --- |
| `.html` | 双击在浏览器中打开的阅读版聊天记录 |
| `.json` | 含消息编号、备份信息、文字和 HTML，用于下次增量备份 |

文件名中可能出现的提示：

- `full`：脚本认为完成了一次完整扫描；仍应核对开头、结尾及警告。
- `incremental`：找到了新旧分界，保存新增/有变化的记录。
- `FULL-rescan-NOT-incremental`：没确认增量分界，重新扫描到顶部，**不是增量**。
- `PARTIAL` / `PARTIAL-unconfirmed`：**不完整**，不能当作可靠的完整备份。
- `-GAPS`（v1.2 起）：扫描中有地方没接上，**可能漏了消息**；增量备份带这个标记时，建议改做一次完整备份。

运行中如需停止，可在控制台输入 `ccStop()` 回车，已收集内容会尽量保存并标注状态。浏览器没有成功弹出下载时，可以在同一页面输入 `ccSave()` 尝试重新下载。

## 特别重要：局限与安全

1. **一定要趁还能登录时备份。** 账号无法访问或会话已不可打开时，本工具无法找回历史记录。
2. **能抓取的是网页里成功加载的内容。** 如果更早的消息没有加载出来，可能漏存。建议人工预滚动并在导出后检查首尾和异常提示；即使页面到了顶部，也不代表必然完整。
3. **这不是 Claude Code Session 的运行状态快照。** 它不会保存/恢复内部上下文、执行环境、工具状态或 Claude 的隐藏信息；不能“导入后继续原来的对话”。
4. **媒体与复杂内容可能不完整。** 当前脚本将图片保存为文字占位符，不会下载原图；音视频、交互组件、部分特殊 UI 或附件可能无法还原。
5. **页面改版可能使脚本失效。** 脚本目前以 Claude Code Web 的 `[data-testid="transcript-row"]` 等页面元素识别消息；不保证兼容普通 Claude Chat、手机版或未来版本。
6. **本地文件也要保护隐私。** 备份可能包含对话正文、代码、链接及会话地址；不要把真实聊天备份文件上传到公开 GitHub 仓库或发到评论区。
7. **控制台脚本需要谨慎。** 即使这份代码没有主动外传逻辑，也建议自己阅读或让可信的 AI 审查。不要运行被人替换、来源不明的脚本。

## 想用于普通 Claude Chat？

原理相通，但网页结构不同，**不要直接把本工具当作 Claude Chat 已兼容**。仓库内有一份可交给 AI 的 [`PROMPT.md`](./PROMPT.md)，帮助你根据实际网页制作或适配脚本。适配前请先检查对应页面的 DOM 结构。

## 一句话简介（小红书可用）

> Claude Code 云端会话本地备份工具：浏览器控制台运行，支持完整/增量备份，导出 JSON + HTML。不依赖平台提供导出按钮，但也不是官方恢复或完整数据导出方案。**请在仍能访问会话时提前备份。**

## 关于项目

- 当前脚本版本：`1.2`。
- **v1.2 修复**：往上滚动时，如果网页在顶部补加载更早的消息却没有保持滚动位置，旧版本会跳过中间一整段（增量备份尤其明显：新增很多时会漏掉中间的消息，却仍显示“已确认”）。新版本会把被推走的位置补回来、必要时往下重新找接上的地方；凡是有“没接上”的地方，文件名会带 `-GAPS`，顶部横幅不再显示为绿色。
- **如果你以前的某次增量备份标着“扫描中有 N 处前后没有接上”**：那一份很可能漏了消息，而且之后的增量补不回来。建议用 v1.2 重新做一次完整备份（选文件时点“取消”）。
- 使用方式：直接复制 JavaScript 到自己已登录的会话页面的浏览器控制台。
